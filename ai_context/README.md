# 🚀 راهنمای سریع هوش مصنوعی (AI Fast-Start Guide)

این پوشه (`ai_context/`) به طور اختصاصی طراحی شده است تا هر هوش مصنوعی دیگری (مانند Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro, DeepSeek R1 و ...) بتواند در چند ثانیه کل پروژه **GymBro** را با دقت یک مهندس ارشد درک کند.

---

## 📂 محتوای این بسته:

| فایل | هدف و کاربرد برای هوش مصنوعی |
| :--- | :--- |
| **`01_PROJECT_OVERVIEW.md`** | خلاصه معماری، اهداف تجاری، فلسفه طراحی برند، تکنولوژی‌ها و وضعیت فعلی پروژه |
| **`02_DESIGN_SYSTEM_&_RULES.md`** | سیستم طراحی اختصاصی، توکن‌های رنگی، فونت وزیرمتن، قوانین تجربه کاربری و WCAG 2.2 AA |
| **`03_DATA_MODELS_&_STATE.md`** | معماری کامل State Management (`AppState`)، مدل‌های داده و متدهای کلیدی ذخیره‌سازی |
| **`04_SCREENS_&_USER_JOURNEYS.md`** | نقشه تفکیک‌شده صفحات ۵ گانه برنامه، ویجت‌های اختصاصی هر صفحه و جریان‌های کاربری |
| **`05_CORE_ALGORITHMS.md`** | موتور محاسباتی بیومکانیک و متابولیک خالص دارت (TDEE, BMR, Brzycki 1RM) |
| **`06_QA_&_TESTING_STANDARDS.md`** | وضعیت تست‌ها (۲۲۷/۲۲۷ پاس شده)، قوانین ضد Overflow و چک‌لیست تغییرات امن |
| **`07_ENVIRONMENT_&_MIGRATION_GUIDE.md`** | مشخصات محیط اجرا، SDK، دستورات بیلد/تست، و راهنمای مهاجرت/تعویض دیتابیس، AI و پلتفرم |
| **`ui_inspector.html`** | 🎨 **داشبورد بصری فرانت‌اند (HTML Viewer):** مشاهده صفحات زنده، تصاویر رندر شده، شبیه‌ساز موبایل و کدهای مرجع فرانت‌اند |

---

## 🎯 نحوه استفاده:
1. **اگر می‌خواهید فرانت‌اند را به صورت بصری و تعاملی ببینید:** کافیست فایل `ui_inspector.html` را در هر مرورگری (Chrome, Edge, Firefox) باز کنید. تمام ۹ صفحه اصلی برنامه داخل فریم موبایل شبیه‌سازی شده و جزییات معماری هر صفحه در کنار آن قرار دارد.
2. **اگر می‌خواهید پرامپت کوتاهی بفرستید:** فقط محتوای فایل `01_PROJECT_OVERVIEW.md` را کپی کنید.
3. **اگر روی UI و طراحی کار می‌کنید:** فایل‌های `01` و `02` و `04` را ارائه دهید.
4. **اگر روی لاجیک، فرمول‌ها یا باگ‌های دیتابیس کار می‌کنید:** فایل‌های `01`، `03` و `05` را ارائه دهید.
5. **اگر می‌خواهید محیط اجرا را تغییر دهید یا به دیتابیس/سرور واقعی وصل شوید:** فایل‌های `01` و `07` را ارائه دهید.
6. **تغذیه کامل برای چت‌های طولانی:** می‌توانید کل این فایل‌ها یا فایل مادر `01_PROJECT_OVERVIEW.md` را کپی کرده و به عنوان پرامپت سیستمی قرار دهید.
