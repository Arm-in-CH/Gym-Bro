# Glossary

| Term | Meaning |
|------|---------|
| Toman | Iran's everyday pricing unit. 1 Toman = 10 Rial. All GymBro prices in this vault are Toman unless stated otherwise |
| MVP | The minimum feature set for GymBro's first real launch — see [[Feature Map]] |
| Elite | Earned (not purchased) top user status — see [[Levels Ranking and Elite Status]] |
| sales_agent | Phase 2/3 internal role for cold-outreach onboarding of gyms/trainers — see [[Sales Team (Future)]] |
| Partnership program | The zero-commission + referral-day-credit incentive for the first 12–15 trainers — see [[Trainer Partnership Program]] |
| DragonflyDB | Redis-API-compatible cache, used from project start — see [[Infrastructure and Hosting]] |
| RBAC/PBAC | Role-based / permission-based access control — see [[Roles and Permissions]] |
| SportBro | Planned Phase 2 expansion of the same marketplace model to other sports — see [[Roadmap and Phases]] |
