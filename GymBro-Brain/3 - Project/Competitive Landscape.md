# Competitive Landscape

## What's actually been established
- **MyFitnessPal** referenced once, only as a global pricing comparison point (~$15/month) — not a direct competitor analysis
- **Uber** and **Snapp** referenced repeatedly as the *structural model* (two-sided marketplace, driver-style supply acquisition, BD-style cold outreach) — not fitness competitors
- No Iranian fitness-app competitor has actually been researched or named in any discussion

## Open gap
A real competitive analysis (local Iranian fitness/booking apps, gym-membership platforms, existing trainer-marketplace attempts) has not been done. Differentiation claims in [[Product Vision]] are reasoned from first principles (filtering, language, currency, local trainer network), not from a documented gap analysis of named competitors.
