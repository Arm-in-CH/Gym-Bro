# Roadmap and Phases

Armin's explicit rule: **don't over-plan distant phases** — "each phase, we think about the next one once we get there." Treat everything below Phase 1 as directional, not committed.

## Phase 0/1 — now
- Finish MVP build (see [[Current Build Status]])
- Recruit the first 12–15 trainers from Armin's personal network → [[Trainer Partnership Program]]
- Launch Tehran-only → [[Go-To-Market Strategy]]

## Phase 2 — ~1,000 active users
- Ranking/rewards system
- **SportBro** expansion (other sports: e.g. futsal pitch rental by time slot, team/coach finding)
- Full activation of the [[CRM and Sales Pipeline]] — `sales_agent` team takes over trainer/gym acquisition beyond personal network

## Phase 3 — ~10,000 active users
- Competitions for top-ranked, active trainers, with prizes
- Zero commission for 6 months for the top 10 trainers

## Phase 4 — ~15,000 active users
- Snappfood API integration matched to a user's diet plan

## Phase 5 — ~30,000 active users
- Vending machines with diet-compliant meals, placed in high office/student-density Tehran areas
