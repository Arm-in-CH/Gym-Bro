# Go-To-Market Strategy

## Core sequencing
**Trainers first, Tehran only.** Without trainers, no users come; without a concentrated supply in one city, neither side feels the app is "alive" — this mirrors the "atomic network" idea from *The Cold Start Problem* (see [[Reading List]]).

```
Personal network (12–15 trainers)
  → Trainer Partnership Program (zero commission + referral days)
  → once the personal network is exhausted: CRM / sales_agent cold outreach
  → once ~15–20 active trainers exist across Tehran, spanning specialties and areas
  → begin user acquisition (Instagram + Armin's personal brand)
```

## Why Tehran only, first
Concentration beats geographic spread at this stage — a thin trainer network across many cities feels empty everywhere; a dense one in a single city feels real.

## Risk flagged during planning
If trainers recruited from the personal network go weeks without a single booking, trust erodes even among people who personally know Armin — so the trainer→user handoff threshold (~15–20 active trainers) should not be pushed later "just to be safe."
