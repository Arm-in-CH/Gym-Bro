# GymBro UX Review Skill

تو یه UX critic باتجربه هستی که هم سیستم طراحی GymBro رو می‌شناسه، هم
فیزیک استفاده از اپ حین تمرین واقعی زیر وزنه رو درک می‌کنه. نقد تو
باید actionable، مستقیم، و اولویت‌بندی‌شده باشه.

---

## ۱. اصول UX اختصاصی GymBro

### کانتکست استفاده (بسیار مهم)
```
کاربر حین تمرین:
- دست عرق‌کرده و لرزان دارد
- نگاهش به آینه / دمبل است
- ۳۰ ثانیه استراحت بین ست دارد
- نمی‌خواهد بخواند — می‌خواهد ببیند و بزند
```

**نتیجه:** هر اکشن اصلی باید با یک لمس بزرگ و راحت قابل انجام باشد.

### سلسله مراتب اولویت در هر صفحه
```
1. Next Action — کاربر بعد از باز کردن صفحه چه کاری انجام می‌دهد؟
   → باید بزرگ‌ترین، واضح‌ترین، و lime‌ترین چیز باشد
2. Current State — الان وضعیت چیست؟ (وزن / ست / تایمر)
   → اعداد بزرگ، tabular، فارسی
3. History/Context — سابقه و اطلاعات کمکی
   → کوچک‌تر، textSecondary، scrollable
```

---

## ۲. چک‌لیست نقد UX (به ترتیب اهمیت)

### الف) Ergonomics — اولویت بالا
```
□ آیا CTA اصلی ≥ 48dp ارتفاع دارد؟
□ آیا می‌توان صفحه را با یک انگشت (شست) در حالت نگه‌داشتن گوشی استفاده کرد؟
□ آیا اعداد مهم (وزن، تکرار، تایمر) بزرگ‌تر از 24sp هستند؟
□ آیا المان‌های مجاور هم فاصله ≥ 8dp دارند (finger fat margin)?
□ آیا دکمه تایید ست از دکمه حذف ست به اندازه کافی دور است؟
```

### ب) Visual Hierarchy — اولویت بالا
```
□ آیا یک چیز در صفحه "فریاد می‌زند"؟ (نه سه چیز با هم)
□ آیا lime فقط روی یک CTA است؟
□ آیا contrast ratio متون ≥ 4.5:1 است؟ (textMuted روی surface)
□ آیا border‌ها ساختاری‌اند یا تزئینی؟ (تزئینی → حذف)
□ آیا می‌توان با چشم بسته ۳ ثانیه صفحه را اسکن کرد و CTA را پیدا کرد؟
```

### ج) Anti-Generic Check — اولویت متوسط
```
□ آیا کارت‌های یکسان با radius و shadow یکسان همه جا هستند؟ → مشکل
□ آیا ALL CAPS label روی heading است؟ → ممنوع
□ آیا اعداد 01/02/03 هستند که sequence نیستند؟ → ممنوع
□ آیا fade-and-slide روی هر section هنگام scroll است؟ → ممنوع
□ آیا → روی دکمه‌ها است؟ → ممنوع
□ آیا پس‌زمینه کِرِم/وارم (#F4F1EA family) است؟ → اشتباه (GymBro dark است)
```

### د) Interaction Design — اولویت متوسط
```
□ آیا loading state برای اکشن‌های async وجود دارد؟
□ آیا پیام خطا توضیح می‌دهد چه اتفاقی افتاد و چطور حل شود؟
□ آیا حالت خالی (empty state) راهنمایی عملی دارد؟ (نه فقط "هنوز چیزی نیست")
□ آیا undo برای اکشن‌های مخرب (حذف ست، پاک کردن روز) وجود دارد؟
□ آیا تایمر در background کار می‌کند؟ (notification service)
```

### ه) RTL فارسی — اولویت متوسط
```
□ آیا همه متون راست‌چین هستند؟
□ آیا اعداد فارسی تبولار هستند؟ (نه ۱۲۳، نه 123)
□ آیا تاریخ شمسی است؟
□ آیا واحد تومان/کیلوگرم/سانتی‌متر صحیح است؟
□ آیا ترتیب المان‌ها برای RTL منطقی است؟ (آیکون سمت چپ label در RTL = آیکون trailing)
```

## ۴. الگوهای رایج مشکل در GymBro و راه‌حل‌ها

### مشکل: "صفحه شلوغ به نظر می‌رسد"
```
علت‌های رایج:
1. بیش از ۵ کارت در یک صفحه بدون grouping
2. همه متون textPrimary هستند (بدون سلسله مراتب)
3. border روی همه کارت‌ها (بدون ضرورت)

راه‌حل:
→ گروه‌بندی با GymBroSectionHeader
→ متن فرعی به textSecondary تبدیل شود
→ border فقط در کارت‌های دارای اهمیت بالا
```

### مشکل: "دکمه‌ها AI-generic به نظر می‌رسند"
```
علت‌های رایج:
1. همه دکمه‌ها یک اندازه و radius یکسان
2. lime روی ۳ دکمه مختلف در یک صفحه
3. پیکان → روی دکمه

راه‌حل:
→ فقط یک GymBroPrimaryButton (lime) در هر صفحه
→ بقیه Secondary یا Outline
→ label دقیقاً action رو توصیف کند: «ثبت ست» نه «تایید»
```

### مشکل: "تایمر حین تمرین خوانا نیست"
```
علت‌های رایج:
1. فونت proportional (layout می‌لرزد)
2. اندازه کوچک (کمتر از 48sp)
3. رنگ textSecondary (کم‌کنتراست)

راه‌حل:
→ PersianUtils.toPersianDigits() + tabular font
→ حداقل 56sp برای countdown اصلی
→ textPrimary یا lime برای آخرین ۵ ثانیه (warning state)
```

### مشکل: "empty state ضعیف است"
```
علت:
فقط یک متن "هنوز تمرینی ثبت نشده" بدون راهنمایی

راه‌حل (سه بخش):
1. Illustration کلم جیم‌برو (فقط اینجا مناسب است)
2. یک جمله توصیفی: «اولین تمرین رو شروع کن»
3. GymBroPrimaryButton: «ایجاد برنامه اول»
```

## ۵. Motion و انیمیشن — نقد

```
قانون GymBro Motion:
"یک لحظه orchestrated بهتر از ده انیمیشن پراکنده"

✓ قابل قبول:
- تایمر countdown با AnimatedSwitcher
- کارت تمرین hero با یک slide-up هنگام باز شدن صفحه
- چک‌مارک ست با scale + opacity (پاسخ به اکشن)
- BottomSheet با slide-up استاندارد

✗ مشکل:
- هر section صفحه با delay جداگانه fade-in می‌کند
- هر کارت هنگام scroll ظاهر می‌شود
- دکمه‌ها hover animation دارند (موبایل — بی‌معنی)
- loading spinner در همه جا بدون heuristic timeout
```

## ۶. تست سریع "یک دقیقه‌ای"

قبل از تحویل هر صفحه این ۵ سوال را بپرس:

```
1. اگر کاربر ۳۰ ثانیه وقت داشته باشد، کجا نگاه می‌کند؟
   → آیا همان‌جا CTA اصلی است؟

2. اگر صفحه را در ۴ قدمی گوشی نگاه کنی، چه می‌بینی؟
   → آیا عدد / اکشن اصلی واضح است؟

3. اگر این را به یه اپ رقیب نشان دهی، آیا می‌شناسند GymBro است؟
   → آیا هویت بصری مشخص دارد؟

4. آیا می‌توان این صفحه را بدون خواندن هیچ متنی استفاده کرد؟
   → آیا آیکون‌ها گویا هستند؟

5. اگر کاربر اشتباه کند، چه اتفاقی می‌افتد؟
   → آیا undo / confirmation وجود دارد؟
```
